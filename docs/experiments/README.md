# 評価実験の記録

Re-ID の精度検証について、実験ごとの記録と結果CSVを保管する。

## 実験の一覧

| 実験ID | 目的 | 画像 / 人物 / ペア | 重み | 主な結果 |
|---|---|---|---|---|
| `web-photos__imagenet-weights__2026-08-17` | オープンキャンパスと同条件（ImageNet重み）での測定 | 9 / 6 / 36 | ImageNetのみ | 同一min 0.7586 / 別人max 0.9363。**分離せず** |
| `web-photos__weights-comparison__2026-08-17` | Re-ID用の重みで精度が上がるか。切り出し範囲の影響も測定 | 12 / 9 / 66 | 7種 | **全7重みで分離せず** |
| `web-photos__manual-crop-comparison__2026-09-10` | 入力画像の余白が精度に影響するか | 19 / 9 / 171 | 7種 | **未集計** |
| `market1501__unseen-data-check__2026-09-17` | 学習に使われていないデータでOSNet自体の性能を確認 | 15入力 / 14使用 / 3 / 91 | MSMT17のみ | 中央値の差 0.4221。**実装は正常** |

実験の詳細は、それぞれ `<実験ID>.md` を参照。

## 命名規則

```
<データ>__<検証内容>__<日付>
```

- 区切りは `__`（アンダースコア2つ）。単語の中は `-`
- 重み名は元の表記のまま（`osnet_x1_0_msmt17`）。内部に `_` を含むため、区切りと区別する
- 日付は末尾。同じ種類の実験が隣り合うように並ぶ

| 種類 | 形式 | 例 |
|---|---|---|
| 記録 | `<実験ID>.md` | `market1501__unseen-data-check__2026-09-17.md` |
| 結果CSV | `results/<実験ID>__<重み名>__<日付>.csv` | `results/market1501__unseen-data-check__osnet_x1_0_msmt17__2026-09-17.csv` |

**`results/` にサブディレクトリを作らないこと。**
`.gitignore` は `*.csv` を除外し、`docs/experiments/results/*.csv` だけを例外にしている。
階層を作ると、そのCSVは追跡されない。

## ディレクトリの分担

| 場所 | 内容 | git |
|---|---|---|
| `docs/experiments/` | 記録mdと結果CSV | **追跡する** |
| `tests/<実験ID>/` | 入力画像・YOLO切り出し・生の出力 | 除外 |
| `production/` | 本番（オープンキャンパス）の実行履歴 | 除外 |

`tests/<実験ID>/` の中身は、どの実験でも同じ構成にする。

```
tests/<実験ID>/
├── input/<条件フォルダ>/   入力画像
├── yolo-crops/             YOLOが切り出した画像
└── results/                CSV・ログ
```

`yolo-crops` という名前にしているのは、**手作業で切り出した画像（入力）と
YOLOが切り出した画像（出力）を区別するため。** 過去に `crops` / `crops_v2` /
`*-crop.jpg` が混在し、どちらの切り出しか判別できなくなったことがある。

## 実験記録に必ず書くこと

| 項目 | 理由 |
|---|---|
| 目的・仮説 | 後から読んで何を知りたかったかが分かるように |
| **データの出所・取得日・選定方法** | 画像はgitで追跡しないため、記述だけが再現性を担保する |
| モデルと重みファイル名、**重みの入手元** | 重み未指定でImageNet重みのまま動いていた事例があるため |
| **実行コマンドの全文** | 再現の最短経路 |
| コミットハッシュ | コードが変わっても当時の状態に戻れる |
| 結果の数値 | |
| **確認できたことと、未検証・推測の区別** | 事実と解釈を混ぜない |
| 制約・記録事項 | 数値を過信しないため |

## 実験の進め方

- **1実験につき、変えるのは1つだけ。** 重みを変えるならデータは固定、データを変えるなら重みは固定
- 結果が出なかった実験、途中で止めた実験も同じ形式で記録する
- `docs/experiments/results/` の既存ファイルを上書きしない。過去の結果は復元できない
- gitで管理するファイルはホスト側で作成する（コンテナ内で作ると root 所有になる）
